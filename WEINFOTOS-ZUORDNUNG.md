# Weinfotos für DeidiVino

## Grundsatz

In die Website kommen nur Fotos, an denen DeidiVino eigene Nutzungsrechte besitzt oder für die eine ausdrückliche, nachvollziehbare Freigabe vorliegt. Öffentlich sichtbare Produktfotos von Weinguts- oder Händlerseiten werden nicht automatisch übernommen.

Bis ein freigegebenes oder eigenes Foto vorliegt, zeigt die Website einen neutralen Platzhalter. Die Bildfläche und die Vergrößerung im Wein-Detailfenster sind bereits vollständig vorbereitet.

## So werden eigene Fotos zugeordnet

1. Die Wein-ID steht am Anfang jeder Zeile in der folgenden Liste.
2. Bitte das Foto möglichst frontal, auf hellem ruhigem Hintergrund und vollständig beschriftet aufnehmen.
3. Originaldateien dürfen zunächst JPG, PNG oder HEIC sein.
4. Beim nächsten Update werden sie auf ein einheitliches Format zugeschnitten, optimiert und unter ihrer Wein-ID eingebunden.
5. Unterschiedliche Jahrgänge erhalten immer getrennte Fotos.
