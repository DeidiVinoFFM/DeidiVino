# DeidiVino – Aktualisierung auf Version 2

Diese ZIP-Datei enthält das vollständige, aktualisierte Website-Projekt.

## So spielst Du die Aktualisierung bei GitHub ein

1. ZIP-Datei auf Deinem Computer entpacken.
2. In GitHub das Repository `DeidiVinoFFM/DeidiVino` öffnen und im Reiter **Code** in das Hauptverzeichnis wechseln.
3. **Add file** → **Upload files** auswählen.
4. Den **Inhalt** des entpackten Ordners in das Upload-Feld ziehen – nicht die ZIP-Datei und nicht den umschließenden Ordner.
5. Prüfen, dass unter anderem `app`, `public`, `.github`, `.openai`, `scripts` und die Dateien aus dem Hauptverzeichnis hochgeladen werden.
6. Unten als Commit-Nachricht beispielsweise `DeidiVino Website Version 2` eintragen und **Commit changes** anklicken.
7. Der Workflow **Publish DeidiVino to GitHub Pages** startet automatisch. Im Reiter **Actions** warten, bis der Lauf grün markiert ist.
8. Danach die veröffentlichte Website neu laden. Falls noch die alte Fassung erscheint, einmal mit `Strg` + `F5` aktualisieren.

- Navigation ohne störenden URL-Sprung zum Weinbereich
- Anfrageleiste blendet sich vor dem Footer und den Rechtstexten aus

- Preishinweis an die Kleinunternehmerregelung nach § 19 UStG angepasst
- GitHub-Actions-Workflow enthält die bereits benötigte Rechtekorrektur für die Build-Skripte
