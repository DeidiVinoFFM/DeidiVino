# SEO nach der Veröffentlichung

1. In der Google Search Console eine Domain-Property für
   `charakterimglas.de` anlegen.
2. Dort die Sitemap
   `https://www.charakterimglas.de/sitemap.xml` einreichen.
3. Die Startseite anschließend mit „URL-Prüfung“ prüfen und einmalig die Indexierung beantragen.
4. Bei größeren Sortiments- oder Textänderungen muss nichts manuell neu eingereicht werden;
   die Sitemap bleibt unter derselben Adresse und wird beim Deployment aktualisiert.

Hinweis: `www.charakterimglas.de` ist die kanonische Website-Adresse. Die
Weiterleitung von `charakterimglas.de` auf `www` erfolgt über GitHub Pages.
Die `robots.txt` muss im veröffentlichten Root liegen.
