# DeidiVino – Aktualisierung auf Version 3.0

## Was ist neu?

- Jeder Wein besitzt jetzt einen Bildbereich direkt unter der Verfügbarkeitsanzeige.
- Solange kein eigenes oder ausdrücklich freigegebenes Flaschenfoto vorliegt, erscheint ein neutraler Platzhalter.
- Ein Klick auf den Weinnamen öffnet eine individuelle Beschreibung der Charakteristik.
- Ein Klick auf den Weingutsnamen öffnet ein Kurzporträt des Weinguts.
- Jedes Weingut ist im Detailfenster mit seiner offiziellen Website verlinkt.
- Im Wein-Detailfenster kann die Flasche direkt für die Anfrage gemerkt werden.
- Die Zuordnungsliste `WEINFOTOS-ZUORDNUNG.md` enthält alle 55 Wein-IDs für die späteren eigenen Fotos.

## Warum sind noch keine fremden Produktbilder enthalten?

Bei der Recherche auf den offiziellen Weingutsseiten ließ sich keine ausdrückliche und nachvollziehbare Freigabe für die kommerzielle Weiterverwendung der Produktbilder durch DeidiVino verifizieren. Öffentlich sichtbare Bilder werden deshalb nicht ungefragt übernommen oder bearbeitet.

## Installation mit GitHub Desktop

1. ZIP-Datei vollständig entpacken.
2. Alle enthaltenen Dateien und Ordner markieren.
3. In den lokalen DeidiVino-Repository-Ordner kopieren.
4. Beim Kopieren vorhandene Dateien ersetzen lassen.
5. GitHub Desktop öffnen.
6. Prüfen, dass als Repository `DeidiVino` und als Branch `main` ausgewählt ist.
7. Als Summary beispielsweise `Website Version 3.0` eintragen.
8. `Commit to main` anklicken.
9. Danach `Push origin` anklicken.
10. Unter GitHub → Actions warten, bis `Publish DeidiVino to GitHub Pages` grün abgeschlossen ist.

## Eigene Fotos nachreichen

Bitte die Originalfotos zusammen mit der jeweiligen Wein-ID aus `WEINFOTOS-ZUORDNUNG.md` bereitstellen. Zuschnitt, einheitliche Helligkeit, Web-Optimierung und die Einbindung in die vorbereiteten Bildflächen können dann in einem kompakten Folgeupdate erfolgen.
