# DeidiVino – Foto- und Kartenupdate 3.1

## Eingebunden

- 17 eigene Flaschenfotos als optimierte WebP-Dateien
- Hochformat-Fotos nun als schlanke Produktfläche rechts in jeder Weinkarte
- Text, Preis und Merken-Schaltfläche bleiben gut lesbar links beziehungsweise unten
- Auf kleinen Mobilgeräten wird die Bildspalte automatisch schmaler
- Detailfenster verwenden die hochaufgelösten Fotos ebenfalls

## Nicht eingebunden

`W0103.heic` enthält im unteren Bereich einen technischen Bildfehler. Daher bleibt der Hop & Grape Perlwein vorerst mit dem neutralen Platzhalter versehen. Bitte diese Flasche bei Gelegenheit noch einmal fotografieren und mit der ID `W0103` hochladen.

## Installation

1. ZIP-Datei vollständig entpacken.
2. Den Inhalt des inneren Ordners direkt in den Hauptordner des lokalen GitHub-Repositories `DeidiVino` kopieren.
3. Vorhandene Dateien ersetzen lassen.
4. In GitHub Desktop als Summary beispielsweise `Website Version 3.1 – erste Weinfotos` eintragen.
5. `Commit to main` und anschließend `Push origin` anklicken.

Die ZIP ist ein Folgeupdate für Version 3.0. Falls Version 3.0 noch nicht eingespielt wurde, bitte zunächst deren vollständiges Update übernehmen.
